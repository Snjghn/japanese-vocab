# 일본어 단어 암기장

사진에서 정리한 일본어 단어를 카드, 퀴즈, 쓰기, 반의어, 한자 묶음 및 한자 쓰기로 공부하는 개인 학습 프로그램입니다.

## 실행

- 웹 앱: <https://snjghn.github.io/japanese-vocab/>
- PC에서는 바탕화면 바로가기로 실행할 수 있습니다.
- iPhone에서는 Safari로 웹 앱을 연 뒤 `공유` > `홈 화면에 추가` > `웹 앱으로 열기` > `추가`를 누르면 앱처럼 실행됩니다.

학습 기록과 설정은 현재 브라우저의 기기에 저장됩니다. PC와 iPhone의 기록은 자동으로 동기화되지 않습니다.

## 단어 데이터

단어 데이터는 `words.js`의 `window.defaultWords` 배열에 있습니다. 새 단어는 이 대화에서 사진이나 목록으로 요청하면 기존 분류와 순서를 유지해 반영합니다.
